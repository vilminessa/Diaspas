# Diaspas (διάσπασις)

Менеджер обхода DPI для Windows: установка релизов
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube),
переключение пресетов стратегий и диагностика доступности
игровых и мессенджерных сервисов (Discord, YouTube, EA,
Ubisoft) одной кнопкой.

> **Diaspas не аффилирован с Flowseal, bol-van или WinDivert.**
> Это независимый инструмент. Сами компоненты обхода
> распространяются по своим лицензиям — см.
> [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Что делает

- **Скачивает релиз** zapret-discord-youtube с GitHub
  (последний релиз, с сохранением `LICENSE.txt`) —
  бинарники не входят в дистрибутив Diaspas.
- **Переключает пресеты**: одна кнопка выставляет стратегию
  `general (ALTn).bat`, режим Game Filter, режим IPSet и
  дописи в пользовательские списки доменов, затем
  переустанавливает службу.
- **Переключает стратегию отдельно от пресета**: выбор хранится
  по конкретной установке, а не глобально — наборы стратегий у
  версий zapret разные, и ALT13 в 1.10.x не должен ломать
  применение в 1.9.x, где такого файла нет. В окне есть
  селектор с явной целью привязки и две кнопки: «Применить»
  (пересоздать службу) и «Запомнить» (без перезапуска).
- **Ставит несколько версий zapret**: Flowseal (`general*.bat`)
  и bol-van win-bundle (`preset*.cmd`); реестр установок,
  переключение активной, откат, восстановление файлов из кэша.
- **Диагностирует**: TLS-пробы целевых хостов с учётом
  того, работает ли обход прямо сейчас.
- **A/B-тест**: кратковременно гасит службу и повторяет
  пробы — отделяет «ломает zapret» от «блокирует DPI».
- **Автоподбор стратегии**: перебирает все стратегии
  установки (`general*.bat` или `preset*.cmd`) в одной
  повышенной сессии, рекомендует рабочую и применяет её по
  кнопке «Взять лучшую».

## Пресеты по умолчанию

Стратегия в таблице — **базовая**, её можно поменять для
любого пресета в этой установке (селектор «стратегия»). В
win-bundle вместо `general (ALTn).bat` подставляется первый
`preset*.cmd` — своих `general*.bat` там нет.

| Пресет | Стратегия | Game Filter | IPSet | Списки |
|---|---|---|---|---|
| Discord / YouTube | ALT11 | — | — | — |
| Apex / EA | ALT11 | all | any | `ea.com` в исключения |
| Ubisoft | ALT11 | all | any | `ubisoft.com`, `ubi.com` в исключения |
| Максимум для игр | ALT11 | all | any | — |
| Выкл | — | — | — | — |

## Управление правами

Операции со службой выполняются через служебную задачу
Windows с уровнем Highest: единственный запрос UAC при
регистрации задачи, дальше Diaspas запускает её через
`schtasks /Run` без диалогов. Всего две задачи:
`DiaspasService` (служба) и `DiaspasSelector` (перебор
стратегий).

Состояние службы читается **без прав** (`sc query` +
реестр) — обычная проверка карточки не дёргает UAC.

## Журнал

Все события пишутся в `%LOCALAPPDATA%\Diaspas\diaspas.log`
(UTF-8 с BOM, ротация при 512 КБ). Окно показывает то же
плюс хвост прошлого запуска — закрытое окно больше не
теряет диагностику.

## Запуск из исходников

```
python main.py
```

Зависимости — только стандартная библиотека
(Tkinter, urllib, ctypes). Тесты:

```
pip install pytest
python -m pytest tests/
```

Юнит-тесты (`tests/test_*.py`) не трогают живую систему: служба,
реестр и сеть в них подменены. Ручные прогоны, которые пересоздают
службу и правят списки доменов, лежат в `tests/manual/` и требуют
явного порога — иначе случайный запуск портит живую установку:

```
set DIASPAS_LIVE=1
python tests/manual/run_probes.py        # пробы всех групп
python tests/manual/run_ab.py ubisoft    # A/B-тест по группе
python tests/manual/run_select.py        # автоподбор стратегий
python tests/manual/live_winws_layout.py # win-bundle: стратегии и применение
```

## Сборка

```
pip install -r requirements.txt
python tools/build_ui.py       # ui_src -> ui/bundle.py
pyinstaller diaspas.spec
python tools/smoke_exe.py      # запустить окно, проверить, закрыть
```

Готовый `dist/Diaspas.exe` — onefile, ~20 МБ. Бандл обязан быть
актуальным: `python tools/build_ui.py --check` падает, если `ui_src`
изменён, а `ui/bundle.py` нет (так собранное окно получает старый
интерфейс).

## Статус

Реализовано: установка релизов с GitHub (оба источника), несколько
версий zapret с переключением/откатом/ремонтом, пресеты,
переключение стратегии по установке, управление службой (один
UAC), пробы Discord/YouTube/EA/Ubisoft, A/B-диагностика,
автоподбор стратегий с применением рекомендации, GUI (webview +
Tk-резерв), журнал с хвостом прошлого запуска.

Не сделано пока: редактор пользовательских пресетов в окне
(core их читает), локализация (только русский), самообновление
самой Diaspas, подпись exe. Порядок развития —
[docs/ROADMAP.md](docs/ROADMAP.md).

Проверено на живой системе: A/B достоверно разводит
«ломает zapret» / «блокирует DPI»; пресет «Ubisoft»
чинит `account.ubisoft.com` (было 2/3 → стало 3/3);
перебор возвращается к ALT11/ALT12 как к полным.
