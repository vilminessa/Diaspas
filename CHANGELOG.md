# CHANGELOG

Формат — [Keep a Changelog](https://keepachangelog.com/), версии
соответствуют тегам `vMAJOR.MINOR.PATCH`; бета-теги `b*` помечены
отдельно.

## [Не выпущено]

### Добавлено

- Переключение стратегии пресета: выбор хранится по установке
  (`settings.preset_strategies` вложенным словарём по пути), в окне
  — селектор с явной целью привязки и кнопками «Применить»/«Запомнить».
  Раньше стратегия была константой пресета и «взять лучшую после
  перебора» применялась только к ALT11.
- Второй layout установки: bol-van `zapret-win-bundle`
  (`preset*.cmd` + `winws.exe` рядом) — разбор аргументов winws из
  `.cmd`, список стратегий по layout, дефолт под layout.
- Скачивание любой версии из обоих источников (Flowseal и win-bundle),
  реестр установок с переключением активной, откатом и восстановлением
  файлов из кэша архива.
- Живые прогоны вынесены в `tests/manual/` под порог `DIASPAS_LIVE=1`.

### Исправлено

- Выбор стратегии терялся, если папка установки не найдена: плоская
  запись создавалась и тут же сносилась в том же вызове `set_strategy`.
- Ошибка «нет стратегии» в win-bundle не объясняла, что там работают
  `preset*.cmd`, а не `general*.bat`.
- Бандл UI отставал от `ui_src`: собранное окно получало старый
  интерфейс без цели привязки стратегии.

## [0.1.1] — 2026-10-10

### Добавлено

- Несколько версий zapret: реестр установок, переключение, откат, ремонт.
- Надёжность полного цикла: UAC-warm-up при старте, один confirm на
  операцию, контроль старта `winws`, честный источник папки установки.
- Цикл «скачал релиз → создал службу» замкнут кнопкой в окне.
- Интерфейс на pywebview: дизайн-система, три вкладки, мост API.

### Исправлено

- Подсветка активного пресета: маркер `active_preset` в настройках
  различает конфигурационно идентичные игровые пресеты.
- Нормализация кавычек при установке службы (код выхода 1067).
- `ZipInfo.file_size` при распаковке релиза, сверка размера при
  скачивании, персистентный журнал.

## [0.1.0] — 2026-10

### Добавлено

- Ядро: релизы GitHub, служба с обходом UAC через служебную задачу,
  пробы Discord/YouTube/EA/Ubisoft, A/B-диагностика, автоподбор
  стратегий, пресеты.
