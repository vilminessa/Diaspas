# Diaspas — рабочий план (детальная разбивка)

Файл — исполняемый список: что уже сделано, что прямо сейчас в работе, что дальше.
Общая карта этапов с формулировками «зачем» — в `docs/ROADMAP.md`; здесь то же,
но с проверенными фактами состояния, конкретными файлами и критериями готовности.

Снимок сделан 23.10.2026, `main` = `56f6044`.

## Правила работы по этому плану

- Один этап = один коммит (или несколько атомарных коммитов подряд). Сообщение в
  стиле conventional-commit: `feat(core): ...`, `fix(ui): ...`, `test: ...`.
- Критерий готовности этапа (все три зелёные):
  - `python -m pytest -q`
  - `python -m pyflakes core ui tools i18n.py main.py`
  - `python tools/build_ui.py --check` → «ui/bundle.py актуален»
- После этапа — запись в `CHANGELOG.md` в раздел «Не выпущено» (Добавлено /
  Исправлено), и пересборка `dist/Diaspas.exe` перед ручными проверками.
- Живые прогоны (UAC, служба, сеть) не входят в pytest: они в `tests/manual/`
  под порогом `DIASPAS_LIVE=1`.
- Ветки: работа идёт в `main`; `dev` отстал на 10 коммитов (`git rev-list --count
  dev..main`) и опережает `main` на 0 — пересинхронизировать до `main` и дальше
  вести `dev → PR → main` (см. Этап F). `origin/main` тоже отстаёт: push пока не
  выполнен.

## Что сейчас в работе (незакоммичено)

- `core/autoselect.py` (+97): TTL кэша подбора (`load_best(install, max_age)`,
  `best_age`), пересчёт «лучшей» по факту замеров вместо «первой подошедшей»

4. Тесты на новую логику: `pick_best` (partial лучше пустого, tie-break по

## Этап B — «диагноз одной кнопкой» и watchdog

   пресета» / «WinDivert не загрузился». Кнопка в блоке «Проверить всё»
   (`ui_src/index.html:151`), результат — карточка + строка в журнал.
2. Watchdog: падение `winws` после старта (код 1067 уже читается,

3. История сравнения «было/стало» по каждой цели проб поверх

4. Тесты: вердикты `diagnose` на фиктивных отчётах проб; watchdog на

Готовность: пользователь с одним кликом получает, что сломано и что делать;

## Риски, которые закладываются заранее

- `WinDivert64.sys` блокируется антивирусом — нужен явный путь диагностики
  (Этап B), а не `1067`.
- Upstream zapret меняет имена файлов стратегий: каталог строится из папки
  установки (`core/presets.py:170`), а не из списка в коде — вектор верный,
  довести до конца в Этапе C.
- Реестр/`schtasks` и UAC ведут себя по-разному на сборках Windows: резерв без
  задачи (одна повышенная сессия) обязан оставаться рабочим и тестироваться.
- WebView2 отсутствует → Tk-резерв должен покрывать общие сценарии, иначе
  деградация молчит.
- Лицензия PolyForm Noncommercial ограничивает коммерческое распространение —
  влияет на способы дистрибуции и подписания кода.
