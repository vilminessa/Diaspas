# Живые прогоны (не CI)

Скрипты отсюда трогают реальную систему: пересоздают службу `zapret`,
правят пользовательские списки доменов в папке установки, скачивают
релизы и пишут настройки в `%LOCALAPPDATA%\Diaspas`. В CI или «просто
посмотреть» они запускаются только по явной команде:

```
set DIASPAS_LIVE=1
python tests/manual/run_select.py          # перебор стратегий
python tests/manual/run_ab.py ubisoft      # A/B по группе
python tests/manual/live_winws_layout.py   # win-bundle: стратегии и применение
python tests/manual/integration_webapp.py  # реальный api-цикл
```

Без `DIASPAS_LIVE=1` любой скрипт из этого каталога выходит сразу, ничего
не меняя (см. `_guard.py`). Причина порога: раньше эти скрипты лежали в
`tests/` рядом с юнит-тестами, и случайный запуск портил живую установку и
её настройки — «починить» потом приходилось `restore_*.py`.

Smoke собранного exe живёт отдельно: `tools/smoke_exe.py [путь к exe]`
(или `DIASPAS_EXE`). Он запускает окно и закрывает его деревом, систему не
правит — потому его можно гонять и в CI.
